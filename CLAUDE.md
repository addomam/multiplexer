# amux
Native project-oriented terminal wrapper. Rust daemon, detachable TUI, shared local CLI API, stock Zsh, OMP extension.
Read CONVENTIONS.md before changing code.
Build: `cargo build`
Test: `cargo test`
Lint: `cargo clippy --all-targets -- -D warnings`
Preflight: `cargo test && cargo clippy --all-targets -- -D warnings && cargo build`
Plans and evidence live in specs/.
