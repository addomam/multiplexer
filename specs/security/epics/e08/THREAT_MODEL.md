## Trust and exclusions

No remote service, SQL, web renderer or generic plugin protocol is added. Config is trusted same-UID executable policy, not an attacker sandbox. Do not classify intentional malicious same-UID config/data rewriting as a privilege escalation. File ownership/link/concurrency and unexpected protocol/metadata inputs remain in scope. Native screen/application settlement is the unchanged historical fail-closed/best-effort boundary, not a newly proven guarantee. E05 stays parked; historical review/provider caps remain unchanged. Native Codex installed0.165/live provider acceptance and Linux/minimum-Rust runtime are not claimed. New provider requests0; no global auth/config/daemon/install/publication mutations.

Independent reviewers must report concrete file:line/dataflow/causal scenarios; supported security findings at confidence8/10+ block acceptance when HIGH. No new detection rules or security-skill changes are introduced.

Darwin clock source: [XNU clock.c](https://github.com/apple-oss-distributions/xnu/blob/main/osfmk/kern/clock.c) adjusts clock_boottime on settimeofday; [proc_info.c](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/kern/proc_info.c#L701-L702) exports stored process start fields. Wall-clock correction is therefore not a boot change. Current process UUID/birth exclusion is exercised; no actual global clock-shift experiment or cross-platform runtime acceptance is claimed.
