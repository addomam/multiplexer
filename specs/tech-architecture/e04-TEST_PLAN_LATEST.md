## Levels and fixtures

Push pure framing/validation/state boundaries to module unit tests where they catch plausible consumer bugs. Integration is a new `tests/acp.rs` real-daemon harness with private AMUX_SOCKET/AMUX_RUNTIME_DIR/config/projects/HOME roots and an owned deterministic ACP child: the standalone non-production Cargo example `acp_fixture` at `tests/fixtures/acp_peer.rs`. Parent declares its example target; backend worker owns its source. Its stdout is only ACP, never libtest banners; diagnostics use stderr. Build it explicitly before selected integration-test commands, avoiding nested Cargo builds or Python/Node test requirements. It speaks newline UTF-8 JSON-RPC through real pipes, uses explicit filesystem/socket barriers for races and records only synthetic marker effects/exact frame identities. No network/model/auth. Reuse existing process/controlling-PTY patterns without their separate-transport libtest peer shortcut.

The peer can hold initialize/newSession/prompt, emit request-/session-scoped forms/permissions and mixed updates, stall stdin, flood/malform stdout, write capped stderr, spawn owned descendants and emit error/EOF under controlled ordering. Helpers enforce deadlines for test failure, not production success/cancellation. No fixed sleep as ordering proof. Target effects/dispositions and actual rendered text are the oracle, not forwarding mocks or producer echoes.

Actual CLI/controlling-PTY smoke runs outside the test assertions, using the same deterministic executable and private daemon. A permanent PTY regression is justified for stale input/authority/terminal-injection boundaries, not screenshot wording/layout. Observe cleanup before fixture fallback kills/removes anything, and verify unrelated sentinels survive. Process helpers always reap their own fixtures even on assertion failure.

## Resource/performance/privacy NFRs

PLAN fixes byte/count/process budgets and overflow semantics. Tests send data beyond each boundary and assert actual failed/degraded/unknown outcomes plus concurrent public-operation progress; absence of panic/length checks are insufficient. Schema deserialization is bounded by capped frames/depth and form size/option limits; writer acceptance counts reserved and in-flight messages. Stderr overflow must not block the child. Transcript eviction publishes cursor gaps without evicting active RPC/responders; TUI consumes incremental projections rather than cloning history every frame.

Capture only safe identities/versions/model names, dispositions, command/count/cleanup results in committed evidence. Do not commit real prompt/answer/output/auth/env/provider-home paths or raw transport. Private temporary proof is removed after redacted evidence and actual cleanup observations. Cleanup fallback must not run before the observation under test. None of these scenarios authorizes real provider calls, default daemon contact, global config/auth changes, or ACP merge/push/release.
